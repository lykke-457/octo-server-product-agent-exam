# 源码引用规范

## 必须格式

```text
来源: <相对路径>#L<起>-L<止>
```

示例：

```text
来源: modules/bot_api/auth.go#L25-L43
```

## 答题规则

- 每个关键结论至少一个来源。
- 一条来源只证明它实际覆盖的结论。
- 引用必须来自当前锁定 commit。
- 路径不存在、行号对不上，视为无效证据。
- 找不到证据时说“不确定”，说明要补哪块知识。

## 禁止

- 禁止用 README 架构表替代真实代码证据，除非问题问的是 README 描述。
- 禁止编造文件路径、函数名、行号。
- 禁止把推测写成确认结论。
